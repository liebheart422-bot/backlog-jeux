#Backlog jeux video

site pour gerer sa list de jeux video : a jouer, en cours terminés, abandonnés.

## Fonctionnalités

-Inscription / connextion (JWT)
-Ajouter, modifier, supprimer un jeu 
-Recherche ety tri
Chaque utilisateur ne voit que ses propres jeux

## Installation

1. `cd backend && npù install`
2. crée un fichier`.env` avec `MONGO_URI` et `JWT_SECRET`
3. `npm run dev`
4. ouvre `frontend/index.html` avec live server

## stack technique

HTML/CSS/JS Node.js Experess mongoDB mongoose JWT bcrypt
